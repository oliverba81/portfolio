# website-scraper *(Showcase – ohne Quellcode)*

**Desktop-Scraper: Webseiten und .eml als strukturiertes Markdown/XML/CSV – inkl. Sitemap-Modus und Bildbeschreibungen.**

## Technologie

Einzeldatei-Python-App: crawlt URLs/Sitemaps/.eml, strukturiert Inhalte und exportiert konfigurierbare Formate.

| | |
|---|---|
| Sprache | Python 3.10+ |
| Runtime | CPython (Windows) |
| Plattform | Desktop (Windows) |
| Frameworks | tkinter / Desktop-GUI |
| Daten | Markdown, XML, CSV, lokale Settings-JSON |
| Integrationen | Anthropic Claude (Bildbeschreibungen), Sitemap/HTTP |
| Konzepte | Web-Scraping, EML-Parsing, Export-Pipelines |
| Kategorie | Tools |
| Produktiv-Repo | öffentlich (für Portfolio ggf. auf privat stellen) |

## Highlights

- Einzel-URL, Sitemap und EML-Verzeichnisse
- Ausgabeformate konfigurierbar
- Windows-Desktop-App mit Tracking der Läufe

## Architektur (grob)

```
Python Desktop → Crawl/Parse → Dateiexport
```
